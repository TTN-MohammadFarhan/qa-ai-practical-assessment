# Test Strategy

## Objective

Validate the end-to-end functionality of the Practice Software Testing application using a combination of manual testing, API testing, exploratory testing, and Playwright automation.

---

# Testing Scope

## UI Testing

- Registration
- Login
- Product Search
- Product Filters
- Product Details
- Shopping Cart
- Checkout
- Invoice Verification
- Logout

---

## API Testing

- User Registration
- User Authentication
- Product APIs
- Cart APIs
- Checkout APIs
- Invoice APIs

---

# Testing Types

## Smoke Testing

Critical business flows required for application stability.

- User Registration
- Login
- Product Search
- Add Product to Cart
- Checkout

---

## Regression Testing

Broader validation after feature changes.

- Product Filters
- Product Details
- Update Cart Quantity
- Remove Product
- Invoice Verification
- User Profile
- Logout
- Negative API Scenarios

---

# Automation Strategy

Framework: Prism Playwright

Automation Scope

- Critical Smoke Flows
- End-to-End Purchase Flow
- Core API Lifecycle
- Invoice Validation

---

# AI Usage Strategy

AI is used for:

- Requirement Analysis
- Risk Identification
- Test Design
- Automation Design
- Documentation
- Debugging

All AI-generated outputs are manually reviewed before inclusion.
