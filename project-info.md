# Project Summary

This project demonstrates an AI-assisted QA workflow using the Practice Software Testing application. The objective is to perform requirement analysis, risk analysis, manual testing, API testing, UI automation, API automation, exploratory testing, prompt engineering, AI validation, and execution reporting while following engineering best practices.

The repository focuses on demonstrating responsible AI usage, prompt refinement, validation of AI-generated outputs, and production-quality automation using the Prism Playwright framework.
